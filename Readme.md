# git-practice-jbfish00

Git fundamentals practice repository for **STAT 386** at BYU. Used to learn and practice core Git and GitHub workflows: initializing repos, staging and committing, branching, merging, and remote collaboration.

## Contents

- `file_1.txt`, `file_2.txt`, `new_file.txt` — tracked practice files
- `new_features.txt` — feature branch exercise
- `gitlog.txt` / `history.txt` — git log output snapshots
- `jokes.txt` — commit message practice file
